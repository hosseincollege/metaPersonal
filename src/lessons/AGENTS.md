# Lesson data style

- Lesson files are JavaScript modules, not JSON.
- Write object property keys without quotes whenever they are valid JavaScript identifiers, including keys in nested lesson data (for example `section`, `topics`, `title`, `content`, `subtopics`, and `details`).
- Keep quotes around string values. Do not change lesson content merely to change key formatting.
- When editing a lesson file, apply this style consistently to every object key in that file.
